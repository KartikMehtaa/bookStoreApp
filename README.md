
## 🚀 Features

- **Frontend**: Interactive user interface for browsing and purchasing books
- **Backend**: RESTful API for managing books, orders, and user authentication
- **CI/CD**: Automated testing and deployment with Jenkins
- **Containerization**: Docker support with Kubernetes orchestration
- **Infrastructure**: Terraform configurations for cloud deployment

## 📦 Getting Started

### Frontend Setup

### Deployment

#### Using Kubernetes
Deploy using the configurations in the `Kubernetes` directory.

#### Using Terraform
Provision infrastructure using the Terraform configurations in the `Terraform` directory.

#### Using Jenkins
Set up CI/CD pipelines using the configurations in the `Jenkins` directory.
